## Findings raised but NOT planned (this run)

These were surfaced and vetted; the user did not select them for plans. Kept here
so a future audit doesn't re-derive them from scratch.

- **Relay "mac"-role takeover** (security, M/MED): `relay/relay.js:138-147` grants
  the "mac" role to any client claiming it and trusts a client-supplied
  `x-notification-secret`. Anyone with a `sessionId` can evict the real bridge
  (persistent DoS) and pre-register their APNs token to receive push previews. Not
  an E2EE break. Deferred — changes core relay connection semantics; revisit if
  self-hosted relays are exposed over untrusted networks.
- **Status-phase normalization drift** (tech debt, M/HIGH):
  `CodexService+History.swift:2657` and `CodexService+IncomingSupport.swift:113`
  classify the same bridge status differently (history vs live). Deferred.
- **Rollout lookup re-walks `~/.codex/sessions` every 250ms** (perf, M/HIGH):
  `rollout-live-mirror.js:160-192` → `rollout-watch.js:457` does a synchronous
  full-tree walk per tick while locating a thread's rollout file. Deferred.
- **Full JSONL read+parse to serve last 5 turns** (perf, M/LOW-MED):
  `session-jsonl-history.js:14-40` reads/parses the whole rollout file to return
  `slice(-5)`. Deferred (fallback path only, limited frequency).
- **No iOS test suite in CI** (tests, L): `build-unsigned-ipa.yml` builds but never
  runs `xcodebuild test`. Deferred — needs a macOS runner + simulator setup.
- **No lint/format tooling** (dx, M): no ESLint/SwiftLint/editorconfig anywhere.
  Deferred — first pass on 27K JS + 355 Swift files needs phasing.
- **README/npm README are byte-identical duplicates** (docs, S): `README.md` ==
  `phodex-bridge/README.md`, no sync mechanism. Deferred.
- **README omits shipped voice + pet features** (docs, S): both fully implemented
  and tested but absent from the feature list. Deferred.
- **No Node `engines` pinning** (deps, S): CI hardcodes Node 20 but neither
  package declares `engines`/`.nvmrc`. Deferred.
- **God-object regression** (tech debt, L): the prior `cleanup/CLEANUP-AUDIT.md`
  top-3 files all grew 20–40% since that audit rather than shrinking. Deferred —
  large refactor needing characterization tests first.
